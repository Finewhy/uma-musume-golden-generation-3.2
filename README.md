# 🌸 Golden Generation — Uma Musume

**A scrapbook dedicated to the Golden Generation of Uma Musume Pretty Derby.**

Golden Generation is a fan-made interactive website inspired by the legendary 1998 generation of Japanese racehorses, brought to life through the characters of *Uma Musume: Pretty Derby*.

Designed with a nostalgic scrapbook aesthetic, the website brings together character profiles, costume collections, interactive activities, and fun details in one place.

## ✨ Features

- **Character Profiles** — Discover the backgrounds, personalities, statistics, and trivia of each character.
- **Costume Album** — Explore different outfits and character illustrations.
- **Interactive Quiz** — Test your knowledge of the Golden Generation.
- **Mini Games** — Enjoy character-themed interactive activities.
- **Creative Doodle** — Draw freely using a selection of colors.
- **Interactive Animations** — Enjoy visual effects, floating decorations, and smooth page transitions.
- **Responsive Design** — Designed to work across different screen sizes.

## 🐎 Featured Characters

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

No frontend frameworks or backend services are required.

## 🚀 Getting Started

You can run the website locally:

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, deploy the project using **GitHub Pages**.
